## 维护规则

- **当前事实优先**：任何“在建、投产、份额、价格、政策生效”等状态判断，发布前须用近 3 个月信源复核
- **一条一证据**：新增条目写清结论、截至日期、来源链接或可定位来源、可信度/待核点
- **主题文件保持短**：只保留当前写作高频、仍可能成立的结论；详细时间线、过期报道和冲突材料转入 `archive/`
- **不覆盖不确定性**：使用 `待复核`、`口径待确认` 等标签，不把二手推断写成确定事实
- **归档只读**：`archive/2026-08-initial-fact-base.md` 保留 2026-08 的完整初版；后续不在其中追加“当前结论”
