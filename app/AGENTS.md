# China Battery Brief — 项目规范

中英双语电池出海新闻网站。React 19 + Vite 前端，Hono + tRPC 后端，Drizzle ORM + MySQL。

## 常用命令

```bash
npm run dev        # 开发服务器（localhost:3000，含 API）
npm run check      # tsc 类型检查（改动后必须通过）
npm run db:start   # 启动项目内绿色版 MySQL（../.local-mysql）
npm run db:seed    # 灌入种子数据
npm run db:backup  # 备份数据库 + assets（写 ../backups/db/，保留 N 份）
npm run db:restore -- <file.sql.gz>   # 从备份恢复（覆盖当前库，谨慎）
```

> **库结构变更一律用 `npm run db:push`**（本项目 `db:migrate` 会挂起）。

## 安全约定（改动安全相关代码前必读）

- 会话 Cookie：`httpOnly` + `SameSite=Lax` + `Secure`（`api/lib/cookies.ts`），勿改回 `None`。
- 认证为**邮箱+密码**：`register`/`login` 签发 JWT（HS256，`APP_SECRET` 签名）写入 `cbb_sid` cookie；`context.ts` 每请求解析 cookie 载入用户。密码用 **scrypt** 哈希（`api/lib/passwords.ts`），`auth.me` 只回公有字段、绝不回 `passwordHash`。`OWNER_EMAIL` 首次注册自动授予 `admin` 角色，`adminQuery` 服务端拦截。
- 限流在 `api/lib/rate-limit.ts`（内存窗口）：tRPC 600/min、`subscribe.email` 5/min、确认/退订链接 30/min。新增公开写接口时须加对应限流。
- 安全响应头在 `api/lib/security-headers.ts`（CSP/HSTS 仅生产生效）；CSRF Origin 校验在 `api/lib/csrf.ts`。
- 请求日志只记 pathname，**禁止记录 query**（不要在日志里带邮箱、密码、token 等凭证）。
- 审计：admin 增删改与登录/注册事件写 `audit_logs`（`api/lib/audit.ts`），写库失败自动降级 stdout，不得让审计调用影响业务响应。
- 部署形态（域名/服务器/CDN）未定前，`X-Forwarded-For` 可信性、HTTPS/HSTS、OAuth redirect allowlist 三项按 `../docs/security.md` 第三节在部署时复核。
- 完整应急手册见 `../docs/security.md`。

## i18n 工作方式

- 文案集中在 `src/i18n/en.ts` 与 `src/i18n/zh.ts`（键必须一一对应），组件用 `t('key')` 取值、`tpl(t('key'), {...})` 插值。
- **禁止在组件里写用户可见的硬编码文案**（alt/aria/document.title 除外），一律走 i18n 键。
- 标题常用 A/Em/B 三段拼接结构（Em 是高亮短语），三段拼起来必须是一句通顺的话。

## 中文排版规范（zh 文案必须遵守）

1. **标题类文案句尾不加句号**：h1、章节标题、卡片标题、按钮、印章、kicker、图注，句尾不加「。」或其它收尾标点（「！？」也尽量不用）。
2. **正文段落**：句中标点正常使用，段末句尾照常加「。」——正文须符合中文书写习惯，这一点与标题类文案相反（第 1 条只针对标题类文案，不要套用到正文）。
3. **字符串不得以标点开头**（，。、；：！？）。A/Em/B 分段拼接时，标点只能落在段尾或句中，避免换行后标点挂在行首。
4. **引号统一用中文标准双引号“”**，不要用「」直角引号（正文与脚注一致）。历史期 045–051 仍用「」，可作为存量不追改，但新写/改写必须用“”。
5. **破折号只留给解释或插入语**，不用它做对比转折（「A——而非B」→「A，而不是B」）。对比用「不是……而是……」「而不是」等显式连接词。
6. **顿号只用于真正并列**；对比转折（「……而非……」）不用顿号，用逗号或连接词。
7. **占位符原样保留**：`{n}` `{no}` `{sites}` `{gwh}` `{v}` 等不可翻译、不可删除。
8. **专有名词保持英文原样**：CATL、BYD、LFP、OBBBA、§45X、GWh、FEOC 等不翻译、不强行中文化。
9. **无官方译名的公司名保留英文**，首次出现配一句身份说明即可，不强行音译（如 Quinbrook 写作「美国能源基建投资公司 Quinbrook」，不加译音名）。机构/公司/人名、品牌模型（EnerC Plus、TENER S）、地名项目名（Supernode、South Pine、Riverina）首现给中文全称或注释，后文沿用。
10. **拒绝翻译腔**：中文必须是自然、克制、有判断的编辑书面语。典型问题与改法：
    - 语义矛盾误用：「腰斩 85%」错（腰斩=减半），应为「暴跌/下降 85%」。百分比必须说清对象：`battery price spreads fell 85%` 译为「储能套利价差一年内暴跌 85%」，不要泛写成「电池价差」或「电价暴跌」。
    - 直译套话：「把形状画了出来」→「画出了这幅轮廓」；「答案有一个名字，值得说准确一点」→「理由很具体，不是……而是……」；「吃满市场风险」→「自己扛下市场风险」；「关闭债务融资」→「撬动那笔融资」。
    - 英文已有惯译就中文化，不中英夹杂堆英文：toll→过网费、market sounding→市场询价、grid-forming→电网构型。正文不使用读者无法理解的纯英文行业缩略语；例如 FCAS 一律写「调频辅助服务」，并明确是其**收入**或**市场成本**在下降，不能写成含混的「FCAS 走向归零」。官方机构、专名或项目名可按第 8、9 条在首次出现时保留英文。
    - 长定语堆砌时断句，避免语序悬空（介词短语「为它……」不置句首，主谓先行）。先写清主语和动作，再补充条件；例如 `constrained industrial land` 要结合后文的紧凑布置来译为「面积受限的工业用地」，不能擅自译成「限制开发用途的工业用地」。
    - 处理比喻或判断句时，先校验主谓关系。「市场才是上限」可作短标题；正文应写「真正决定上限的，只有市场，而不是规则」，不能把“市场”直接等同于“上限”。
11. **中英文母本的关系**：英文通常是事实母本，但不是不可修改的圣经。先保留事实、数字、专名、脚注与论证链；若英文自身存在语义不通、逻辑自相矛盾或不符合全篇主旨的判断句，可以修正英文，并将中文同步为同一意思。不得为了中文顺口而改变事实；不得在未获明确授权时改动脚注。
12. **编辑判断标准**：每一句都应能回答「谁在做什么、什么在变化、为什么重要」。把抽象名词落回具体对象：是套利价差、调频辅助服务收入、市场总成本、项目融资能力，还是系统强度合同。避免把原文修辞逐词搬运；允许重组句序、拆句或改写比喻，只要事实和论证不变。
13. CSS 侧已配置：`html.zh` 下标题/正文启用 `line-break: strict` 与 `hanging-punctuation: first allow-end`（CJK 避头尾），新增中文样式不要破坏这两条。

## 双语新闻稿编辑流程（seed-content 与 seed-content-zh）

修改中文新闻稿时，按以下顺序执行；低能力模型也必须逐项完成，不要只做字面对照：

1. **逐段对照事实**：核对主体、身份、时间、数字、单位、项目阶段、地名、专业能力与脚注编号。英文有“超过四小时”等限定信息时，中文不得泛化成笼统的「长时储能」。
2. **逐句核对逻辑**：检查因果、比较对象、否定关系和判断句的主谓。发现英文句子与标题、前后文或结论冲突时，标出原因；获授权后中英文一起修正。
3. **中文化重写**：以自然中文重写，而非逐词翻译。优先使用「不是……而是……」「真正决定……的是……」等清楚结构；拆开长定语和介词短语；首次出现的公司、机构、项目给出简短身份说明。
4. **术语落地**：所有市场术语都补足实际对象和商业含义。例如，储能在低价时充电、高价时放电，收入来自「套利价差」；调频辅助服务是收入来源而不是一个会自行“消失”的实体。正文中避免 FCAS 一类英文缩略语。
5. **格式终检**：标题类文案无句号、正文段落末句照常加句号；引号使用“”；破折号只作插入说明；占位符、Markdown、加粗、脚注编号与脚注内容按用户授权范围原样保留。
6. **双语同步终检**：若改动分析性结论、标题、dek 或元数据，核对英文稿、中文稿及 `issues-zh.json` 的 title/dek/highlights 是否仍表达同一事实和立场；再运行 JSON 解析与 `git diff --check`。

## 内测开关

`contracts/constants.ts` 的 `OpenAccess.beta`：为 `true` 时全站内容免费开放（无限时免费标注），付费墙、涂黑 teaser 均停用。恢复付费时改为 `false`。
